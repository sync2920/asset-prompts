# 51. 水晶玉の神託、過剰に神々しいジャンガリアン（参照画像ベース）

参照人物の同一性と身体特徴を保持し、ブルーアワーの古い天文台風の占い部屋で、
水晶玉に一匹だけの神々しいジャンガリアンハムスターが神託として現れる幻想的な
ラグジュアリーファッションポートレート。人物の静かな威厳と、演出だけが過剰に
壮麗な小動物との落差を、誇張したリアクションに頼らず描く。

- **アスペクト比:** 4:5 縦
- **成人条件:** 妖艶な衣装と演出は、参照人物が明確に成人の場合のみ使用する
- **見せ場:** 水晶玉を主光源とし、顔・球・両手を結ぶ三角構図。球内の一匹だけのハムスターまで同一ピント範囲に置く
- **衣装:** ミッドナイトパープルの完全に不透明なベルベットロングドレス。見せ場は肩とデコルテの一箇所だけ
- **人物保持:** 参照画像の具体的な髪色・顔立ち・アクセサリー等は本文へ書き写さず、参照画像そのものに語らせる
- **生成物:** `variant-01-frontal-twilight.png` / `variant-02-blue-hour-three-quarter.png` / `variant-03-violet-editorial.png` / `variant-04-golden-oracle-pulse.png`

## 生成時の4バリエーション

1. **正面・残照:** 正面寄りの静かな対称性。窓の低い位置へ金色の残照を細く残し、表情はほぼ無表情の威厳の奥にごく微かな驚きを置く。
2. **右寄り・群青:** カメラを正面からごくわずかに右へ移し、窓の群青を強め、球内の霧が縦に立ち上がる瞬間を捉える。
3. **左寄り・紫:** カメラを正面からごくわずかに左へ移し、紫の空、冷たい縁光、瞳とベルベットの虹色反射を繊細に強める。
4. **金色の脈動:** 水晶の神託が最も明るく脈動した一瞬。球内だけ金色光線と多重虹色光輪を壮麗にし、人物と部屋はローキーのまま保つ。
