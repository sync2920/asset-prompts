# 夜のベッド・背向け振り返り・白シアーオフショルダー（参照画像ベース）

`ideas/README.md` の方針（人物の顔・髪・肌・体型などは参照画像だけから保持）と `expression/01-sheer-skin-intimacy.md` の間接表現手法を併用。透け感は光学言い回し、露出は幾何学的輪郭、下半身はリネンのドレープで覆い、背向けポーズで前面を遮る構成。ネガティブ欄は作らず除外要素は肯定文中に織り込む（ChatGPT画像で除外欄が逆に不安定化することを観察済み）。

- **アスペクト比:** 3:4 縦長
- **見せ場:** オープンバックの背中のアーチ、肩越しの振り返りの表情、シアースリーブとパールビーズのストラップ
- **遮蔽:** 腰から下は白いリネンのドレープで覆う（布が主要な視覚的遮蔽物）。背向けポーズで前面は構造上見えない
- **文脈:** コンテンポラリーファインアート素材研究 × スマホナイトフォトシュート（`expression/01` の枠組み1と3を重ねる）

## 設計メモ

### 間接表現の適用箇所（`expression/01` 対応）

- **透け感** → 光学言い回し（光透過率 / 繊維構造が散乱・透過 / 色調と輪郭を物理的に暗示 / 色温度が移し込まれる）。直接の「透けて見える」不使用。
- **露出** → 幾何学的輪郭（肩とデコルテのライン / 背中のアーチが光に沿って見える）。部位ではなく光に沿った輪郭で語る。
- **下半身** → 白いリネンのドレープで覆い「布が主要な視覚的遮蔽物」。脚の輪郭は「光の反射でほのかに暗示されるのみ」。元のTバック/紐パンは「最小限の細いコードのアクセントが布の上に結ばれる」に変換。
- **親密さ** → 演出・演技の言葉（待ちわびる / 問いかける / 物語を含んだ / 不意を突かれた瞬間）。「誘惑」不使用。
- **文脈** → コンテンポラリーファインアート素材研究 × スマホナイトフォトシュートの二重枠。
- **ネガティブ欄** → 作成せず。除外要素は肯定文中に「清潔」「控えめ」「〜なし」として織り込む。

### 表現を弱める場合の順序（`expression/01` 準拠）

1. シアーを弱める：「光透過率の高いシアーメッシュ」→「マットなホワイトシフォン（透過なし）」「不透明な裏地つき」
2. オープンバックを弱める：「ドレープが背中を覆う」「背中に布がかかる」
3. 夜を昼に変える：ラグジュアリーホテルの朝の光、バスルーム（`01` 参照テンプレ）
4. 構図遮蔽を前面に：体前枕抱き＋W字座り（`08` 参照テンプレ）
