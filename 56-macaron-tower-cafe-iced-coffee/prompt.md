# 56. パティスリーカフェ、マカロンタワーとアイスコーヒー（参照画像ベース・服装スタイリング写し）

`ideas/README.md` の人物参照方針に準拠し、人物の年齢、性別表現、顔、髪、肌、体型、胸と腰まわりの形と自然なボリューム、身長感、プロポーションなどを参照画像から精緻に保持する。依頼時に添付されたスタイリング写真（白シアーシャツ×白キャミソール×ベージュスラックス×シルバー小物×胸元のサングラス）を本文に書き起こし、マカロンが大量に積み上がったパティスリーカフェでアイスコーヒーとマカロンを楽しむ一瞬を雑誌エディトリアル調で切り取る。

- **アスペクト比:** 3:4 縦（頭〜テーブル下まで）
- **見せ場:** 一箇所: 開いた胸元に集まる光り物（引っ掛けたサングラス＋シルバーのレイヤードネックレス）を窓光が掠める瞬間。シアーは不透明キャミを構造にした袖の局所的な透過光のみの副次表現
- **服と仕草の接続:** たくし上げた袖＋シルバーバングル → マカロンを持ち上げる前腕で光を受ける
- **差し替え変数:** かじるマカロンの色（現行ペールピンク）、タワーの位置、視線（現行は手元。カメラ目線に変えると表紙感）、比率（フィード最大表示なら 4:5）
- **例外事項:** シャツはオーバーサイズ（緩い服）だが、前を開けて体に沿うキャミソールを見せる着方なので、シルエットはキャミ側で保持する
- **成人条件:** 昼のカフェ×不透明インナー付きの健全な設計のため色気演出の成人ゲート文は不要。透け表現は袖の光学記述（silhouette only）に限定
- **既存案との差:** `49` は自宅のハンドドリップ、`363` は純喫茶のクリームソーダ。本案は洋菓子店カフェで「マカロンの物量（卓上タワー＋ディスプレイケースの列）」を環境の主役にし、添付スタイリングの服写しを行う点が新規

## 運用メモ

- 人物の参照画像1枚と一緒にプロンプト全文を貼り付けて使用する。人物の具体的特徴（髪色・顔立ち等）は本文に書き写さず、参照画像そのものに語らせる運用。
- 服装は依頼時添付のスタイリング写真から書き起こし済みのため、生成時の服装写真の添付は不要。再現度をさらに上げたい場合は `ideas/394-395` と同じ2画像方式（1枚目=人物/2枚目=服装写真）へ書き換え、本文の `the reference image` を `the first reference image` に、Outfit 冒頭に `as shown in the second reference image` を追加する。
- マカロンが崩れて出た場合は Sweets detail の `smooth domed shells with fine ruffled feet` を強調する。
- サングラスが顔に掛かって出た場合は Avoid の `a second pair of sunglasses or sunglasses worn on the face` を前に出す。
- アクセサリーが増殖した場合は保持ブロック末尾の `no accessories beyond those specified in the Outfit section` を強調する。
- 雑誌感を「作り込んだ表紙風」に寄せたい場合は Pose の視線をカメラ目線（a calm gaze straight into the lens）に差し替える。
