# Visual QA v5

- **01:** PASS — 成人・顔髪・自然な体型は参照人物との整合が良好。無地ダークプラムのトップと、別系統のくすみオリーブ＋エクリュ幾何柄ショーツが明瞭に分離し、低彩度・マット質感・端正な形で洗練されたルームスポーツウェアとして成立。チャコールのマットも完全に独立。軽い痛み反応、安全な低め全身構図、手足指、柄と衣装境界に目立つ破綻なし。後ろ足の踵の上がりは控えめ。
- **02:** PARTIAL PASS — 成人・人物・上下別系統色・チャコールマット・安全な低め全身構図は成立し、配色もダサくない。ショーツ柄はシェブロンより菱形寄りに簡略化。踏み足の足指周辺に不自然な緑灰色の着色と軽い融合感があり、解剖QAで減点。表情も「少し痛い」より微笑みに近い。
