# 足つぼマット・リアクション v7 デザイン設計ノート

本設計は、画像参照元（`main/_profile/01.png`）の成人同一性・プロポーション（豊かで高い位置のバスト・ヒップボリューム、体型ライン）を厳密に保持しつつ、参考画像（`img_971bf78314f3.webp`）の洗練されたクリーンな高機能フィットネスウェア幾何構造を取り入れた3種類の独立した全身バリエーション案（3:4縦構図）である。

---

## 1. 共通設計方針

* **人物・体型の保持**:
  * 参照画像の成人女性の骨格・プロポーション・バストとヒップの自然なボリュームを忠実に保持。
  * 痩身化、脚長加工、若返り、体型改変は一切行わない。
  * デコルテは上品な範囲で自然な上部谷間ライン（partial upper cleavage）を覗かせつつ、胸全体をしっかりと支える構造とし、極端なプランジや露出事故リスクを排除。
* **ボトムスの統一基準**:
  * 3案すべて「ソリッド・マットブラック（無地黒）」。
  * 透け感や光沢のない厚手コンプレッション・テクニカルストレッチ生地。
  * 柄、マイクロプリント、部屋着風カッティング、水着/下着感、ブランドロゴを完全排除。
* **シーンとリアクション**:
  * 8月14日の夏の夜明け（Summer dawn）、清潔な日本のフローリングリビング。
  * 朝焼けの温かいオレンジ〜ピンクの斜光（サイドライト）と室内の涼しいブルーの影の陰影対比。
  * リアクションは「少し痛い / 効いている」程度の抑制された自然な演技（わずかな眉の寄り、小さな呼気、自嘲気味の微笑み、片足の踵をわずかに浮かせて荷重を逃す仕草）。跳躍や絶叫などの過剰なリアクションは排除。
* **カメラとアングル**:
  * 35mm単焦点レンズ、床上55〜70cmの低位から胴体へ向けた安全なローアングル全身構図。
  * 頭頂部から両足先（10本の足指・足裏・土踏まず）、足つぼマットまでが明瞭に収まる配置。
  * 衣服内や股間を煽るアングルを完全に排除し、清潔で品位あるエディトリアル構図を維持。

## 2. 3スロットの個別仕様（遠目での明確な差別化）

### Slot 1: クラシック・アスレチック（Ankle Leggings）
* **トップス**: ウォームアプリコット（Warm Apricot）の太めストラップ・スクープネック クロップドタンク。
  * 幅約3.5cmの幅広ショルダーストラップ、首元と鎖骨をきれいに見せるU字スクープ。
  * アンダーバスト直下のクロップド丈で、ハイライズレギンスとの間に適度な腹部の素肌を露出。
* **ボトムス**: ソリッド・マットブラック ハイライズ・アンクルレギンス（足首丈）。
  * くるぶし直上で足首にジャストフィットするフルレングス仕様。素足の足首・甲との境界が最も引き締まる。
* **足つぼマット**: ミューテッド・ティール（Muted Teal / くすみ青緑）。
  * アプリコットと黒レギンスに対して爽やかで落ち着いた補色コントラスト。

### Slot 2: 構築的スクエア×ミニフレア（Mini-Flare Yoga Leggings）
* **トップス**: ヴィヴィッド・コーラルレッド（Vivid Coral-Red）の構築的スクエアスクープ クロップドタンク。
  * 幅約4cmの幅広ストラップと直線的なスクエアネックの幾何学ライン。
  * 高いサイドカバーとしっかりとしたサポート力でデコルテの立体感を強調。
* **ボトムス**: ソリッド・マットブラック ハイライズ・ミニフレア ヨガレギンス。
  * 膝まではタイトにフィットし、ふくらはぎ下部から裾にかけてごく控えめに広がるミニフレア仕様。
  * 足元にクラシカルな動きと優雅なラインを付与。
* **足つぼマット**: ダスティ・ブルー（Dusty Blue / くすみ青）。
  * コーラルレッドの鮮やかさを引き立てるクールな対比カラー。

### Slot 3: アシンメトリー×5インチショーツ（5-inch Training Shorts）
* **トップス**: サチュレイテッド・サンフラワーオレンジ（Sunflower-Orange）のワンショルダー アシメクロップドタンク。
  * 片肩を約4.5cmの幅広ストラップが通り、反対側の脇は高めのカッティングでしっかりとホールド。
  * 斜めのネックラインが洗練されたスポーティさを演出。
* **ボトムス**: ソリッド・マットブラック ハイライズ・5インチ トレーニングショーツ（太もも丈）。
  * 股下5インチ（太もも中間丈）のタイトなアスレチックコンプレッションショーツ。
  * 太もも外側に沿った曲線の立体シームパネル構造。脚全体の露出度を高めつつ、下着感のない健康的なシルエットを維持。
* **足つぼマット**: グラファイト・グレー（Graphite-Gray / 濃炭灰）。
  * サンフラワーオレンジの力強さを引き締めるダークニュートラルなマット。
