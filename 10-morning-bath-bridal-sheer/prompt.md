# 朝のバスルーム・ブライダル・白シアークチュールドレス（参照画像ベース）

`ideas/README.md` の方針（人物の顔・髪・肌・体型などは参照画像だけから保持）と `expression/01-sheer-skin-intimacy.md` の間接表現手法を併用。透け感は光学言い回し、露出は幾何学的輪郭、下半身はドレス裾の微透け裏地で覆い、朝光とブライダル文脈で健全に収める構成。ネガティブ欄は作らず除外要素は肯定文中に織り込む（ChatGPT画像で除外欄が逆に不安定化することを観察済み）。シアーは上半身に強く、下半身は一段弱く（お尻の輪郭がかろうじて暗示されるかどうかの境界）（`expression/01` の表現を弱める順序のステップ1〜2の中間）。

- **アスペクト比:** 3:4 縦長
- **見せ場:** 肩とデコルテのライン、背中のアーチ、シアースリーブを通した光、裾越しのほのかな腰の輪郭
- **遮蔽:** 腰から下はドレス裾の微透け裏地で覆い、シアーは上半身強・下半身弱。前掛りのポーズで前面は構造上見えにくい
- **文脈:** ラグジュアリーブライダルファッションエディトリアル × 朝のホテルバスルーム（`expression/01` の枠組み2と3を重ねる）

## 設計メモ

### `expression/01` の適用箇所

- **透け感** → 光学言い回し（光透過率 / 繊維構造が散乱・透過 / 色調と輪郭を物理的に暗示 / 色温度が移し込まれる）。直接の「透けて見える」不使用。上半身に強く、下半身に一段弱く適用。
- **露出** → 幾何学的輪郭（肩とデコルテのライン / 背中のアーチが光に沿って見える）。部位ではなく光に沿った輪郭で語る。
- **下半身** → ドレス裾の薄いシルクサテン裏地で覆い「裏地が主要な視覚的遮蔽物」。下半身の透けは上半身より一段抑えられ「ヒップの輪郭が光の中でかろうじて読めるか読めないかの境界」に設定。タオルは使用せず、`ideas/README.md` の「透け感には必ず構造をつくる（不透明な裏地を明記）」原則を緩めに適用（完全不透明ではなくごく薄い裏地）。
- **親密さ** → 演出・演技の言葉（何かに気づいたばかり / 思い出した / 不意を突かれた / リアルで柔らかい瞬間）。「誘惑」不使用。
- **文脈** → ラグジュアリーブライダルファッションエディトリアル × 朝のホテルバスルームの二重枠。

### 脚が異様に長くなる問題への対策

3:4 縦長フレーム＋長いドレス裾の組み合わせで、モデルが縦方向に脚を引き伸ばす破綻が観察された。以下の対策を入れた:

1. **体型保持の明示**: 主要被写体セクションに `ideas/README.md` 共通テンプレートの体型保持言語（参照画像の身長感・胴と脚の比率・頭身比を厳密に保持）を追加し「脚を長く描かない」を明示。
2. **胸の位置の基準点**: ポーズセクションに `ideas/README.md` の「胸の位置は高く」の基準文を追加し、上半身の锚を固定して胴長脚長のバランスを参照に揃える。
3. **フレームを膝上まで**: 「床まで流れ落ちる」全身構図をやめ「膝上〜太もも中部まで」に収め、縦方向の引き伸ばしを構図レベルで防ぐ。
4. **ドレス裾も膝上まで**: 「ウエストから下は…膝上まで覆われ」に修正し、長い裾が縦の視覚的引き伸ばしを助長しないようにする。

### `09` との差異（表現を弱める方向）

- 夜 → 朝（ハイキー寄り、月光はなく朝光）
- ベッド → バスルーム（ドレス裾の微透け裏地で下半身を遮蔽）
- 背向け振り返り → 斜め前掛り（前面はポーズとドレス裾で遮る）
- シアーは上半身強・下半身弱（`09` は腰から下リネンだがシアー全体だったのに対し、`10` は上半身に強く、下半身は薄いシルクサテン裏地でヒップ輪郭がかろうじて暗示される境界に留める。タオルは使わない）

### 表現を弱める場合の順序（`expression/01` 準拠）

1. シアーを弱める：「光透過率の高いシアーチュール」→「マットなホワイトシフォン（透過なし）」「不透明な裏地つき」
2. オープンバックを弱める：「ドレープが背中を覆う」「背中に布がかかる」
3. バスルームを朝キッチンに変える（`ideas/197-199` 参照テンプレ）
4. 構図遮蔽を前面に：体前枕抱き＋W字座り（`08` 参照テンプレ）

### モデル別比較検証メモ

- **ChatGPT 画像**: 最も表現に敏感。下半身の微透けが「かろうじて見える」境界に留まるか、強く出すぎるかが最大の検証ポイント。光学言い回し＋「一段抑えられた」で境界に寄せられるか。除外欄は作らず肯定文中に織り込む方針を維持。強く出すぎる場合は「ごく薄い裏地」→「不透明な裏地」に戻す（`expression/01` の弱める順序ステップ2）。
- **Gemini**: ChatGPT より緩やか。朝＋ブライダル文脈なら概ね安定する見込み。微透けのニュアンスが素直に出るか要観察。
- **Nano Banana**: 最も緩やか。`09` 相当の夜シアーでも安定した実績があるため、`10` の朝＋微透け裏地なら高安定予想。ディテール（パール、レース、シルクサテン裾、ヒップ輪郭の境界）の再現精度を比較する。
