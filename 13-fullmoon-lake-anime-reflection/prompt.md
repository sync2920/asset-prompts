## 設計メモ

### 画風参照画像の翻訳方針

- 参照画像の魅力を、**シアン・コバルト・紫・淡いローズ・暖色光の劇的なグラデーション、筆致のある積層雲、大小の光粒子、宝石のような水、劇場アニメの場面写級の人物線画、境界を柔らかくぼかしたフィルム調のグラデーション陰影、宝石のような瞳、細密な髪と衣装、舞う花びら**へ分解した。
- 満月の夜へ合わせ、夕焼けの暖色は「月光の淡い金色」として限定的に使用する。
- 「アニメ」だけでは簡素なテレビ作画や平坦なベタ塗りへ収束しやすいため、人物、髪、瞳、衣装、背景、光の各要素へ具体的な品質アンカーを追加した。
- 新しい人物画風参照画像からは、成人女性らしい端正な顔、横長の瞳、宝石質感の虹彩、省略しない鼻筋、自然な口元、大きく整理された明暗面、暗部まで細密な髪という人物作画だけを抽出した。金髪、編み込み、黒い衣装、宝石、暖色背景は持ち込まない。
- 参照作品のキャラクター、男性、傘、手紙、文字、ポーズ、海辺の構図は再利用しない。画風と空気感だけを湖の倒影へ適用する。

### 人物作画の改訂（塗り・線・光の品質アンカー）

- 初版は「明快なセル陰影」だけを品質アンカーにしていたが、生成結果が平坦なテレビアニメ調の人物へ収束し、人物画風参照画像の質感と乖離した。
- 参照画像の実体は硬いセル塗りではなく、**プレミアムなセル塗りをベースに影の境界を柔らかくぼかしたグラデーション + 色トレス線（肌は暖褐色、髪は毛色を濃くした色）+ 限定的なブルーム**である。品質アンカーは「モダンアニメのキービジュアル品質」と「劇場アニメの一場面の光・空気感」の併記とした。
- 狙い通りの人物が安定して出た手元の短いプロンプトから、効果が確認できた語彙を採用した: 「日本のアニメ、モダンアニメのキービジュアル、高精細イラストレーション、プレミアムなセル塗り、クリスプで優雅な線、柔らかなグラデーション」の画風タグ、「傑作・最高品質・超高精細・8K・美麗に描き込まれた瞳と髪・プロのイラストレーション」の品質タグ、「ソフトなリムライト・キラキラしたハイライト・ドラマチックな陰影」の照明語彙、「低画質・ぼやけ・歪んだ顔・余分な指・文字・ロゴ・透かし」のコンパクトな除外リスト。
- その手元プロンプト固有の金髪・三つ編みアップ・ターコイズの瞳・黒レースドレス・金のアクセサリーは、人物参照画像から身体的特徴を保持する本案の方針と衝突するため取り込まない。描き方(目・鼻筋・陰影・髪の密度)はすでに人物画風参照画像として抽出済み。
- 「死んだ目」対策: 上下反転の倒影では、モデルが目のハイライトと層構造を落としやすく、光のない平坦な瞳になりやすい。対策は三つ — (1) コミュニティで実績のある英語トークン（highly detailed eyes, sparkling luminous eyes, bright multiple catchlights, intricate detailed iris with highlight layers, glossy moist eyes）をアニメ側指定の中へまとめて置く、(2) チェックリストで目の項目を先頭へ移動する（前半に置くほど優先されやすい）、(3) 「反転しても輝き・キャッチライト・虹彩の層構造を鮮明に保つ」「死んだ目にしない」の負指定を添える。生成後の追い込みは「下半分の目をもっと輝かせて。キャッチライトを強く、死んだ目にしないで」。
- アニメ側の満月が消える失敗も確認した。原因の一つは「満月の反射がきらめきへ砕ける」という表現で、月の円盤自体の省略を許してしまう。「実写の満月と対応する位置に、大きく金色に発光するアニメの満月の円盤を必ず描く」と円盤の存在を明示し、Critical rules にも「実写の満月とアニメの満月は両方必ず描く」を追加した。
- 瞳の輝きは、参照アニメの目のクローズアップを分解して仕様化した: (1) 宝石のような多層虹彩 — 濃い外周リング（限界輪）、深い基調色、下半分へ向かって透過光で明るく透けるグラデーション、放射状の細かな繊維、(2) 上部に大きな白いキャッチライト一つ＋小さな輝きを数点、(3) 眼球表面の潤んだガラスのような濡れた光沢と、下まぶたの縁の細い光。瞳を顔の中で最も強く輝く感情の焦点にする。生成結果の目が「単層の色＋小さなハイライト」で平坦なときは、この三点セットの明記で輝きが戻る。色は人物参照に従い、輝きの構造だけを移植する。
- 目は「上まぶたの落影が虹彩の上三分の一を暗くし、下半分が透過光で発光する」二層構造として明文化した。まつ毛は純黒ではなく髪色と調和した暗色の帯とし、目尻でだけ数本に分離する。
- 頬のレンズ状の光斑と淡い血色、前髪の落影、透過光で透ける後れ毛を追加し、顔を「その場の光の中」に置いた。現実的な首の長さ・肩の傾斜・鎖骨の陰影を明記し、顔だけでなく体も大人の骨格に固定した。
- ブルームの全面禁止を緩和し、髪のリムライト、星座刺繍、ビーズ、キャッチライトへの柔らかな滲みだけを許可した。顔と衣装の線を白く飛ばさない制約は維持する。
- 倒影の顔は上下逆で生成モデルが最も崩しやすいため、「正立のポートレートと同じ正確な顔構造で描く」ガードを反射ブロックへ追加した。それでも顔が崩れる場合は、カメラをさらに水面へ下げて倒影の顔をフレーム内で大きくする構図変更が次の一手。

### スタイル分離の強化（GPT Image対策）

- GPT Image系のモデルは上下でスタイルを混ぜやすく、放置すると実写とアニメの中間的な画風へ収束する。対策は四つ:
  1. 水辺線を「シャープでクリーンな一本の水平境界線」と明示する。
  2. 「水辺線より上だけ（TOP HALF ONLY）」「水辺線より下だけ（BOTTOM HALF ONLY）」のラベルで、各スタイルの適用範囲を空間的に限定する。
  3. 実写側に photorealistic / hyperrealistic / DSLR写真品質 / シャープフォーカス / 自然な毛穴 / リアルな布の皺 のトークンを積む。アニメ側の品質タグと対になる。
  4. プロンプト末尾に「重要ルール（Critical rules）」ブロックを置き、ゼロブレンディング、上=純実写・下=純アニメ、ポーズ・ドレス・髪・構図の連続性（変わるのは描画媒体だけ）を最後にもう一度固定する。
- 生成テストで確認した失敗パターン: 境界・反射の幻想感・ドレスの連続性は成功する一方、**上半分が「高品質デジタルイラスト/セミリアル」へ寄る**。肌が滑らかすぎ、毛穴・写真ノイズ・レンズ感が弱く、髪とドレスにイラスト調の輝きが残る。
- 対策: 各半分に「含めないスタイル」の負指定を追加した（上半分: イラスト調・アニメ調・セミリアル禁止 / 下半分: 写真的質感禁止）。ポジティブなトークンを積むだけでは足りず、反対側のスタイルを名指しで排除する方が効く。Critical rules も「100%実写写真 / 100%アニメスタイル」の表現へ強化し、実写側へ「RAW写真の質感」「肌を滑らかに整えすぎない」「イラスト調の光沢を乗せない」を追加した。
- 二度目の生成テストで確認した、より深い失敗パターン: **プロンプトの長文化そのものがスタイル分離を薄める**。指示が多いとモデルが最重要点（分離）を優先できず、実写/アニメの対を繰り返すほど境界が曖昧になり、アニメ側の人物が実写側とほぼ同じタッチになった。細かい顔の作画指定（色トレス、虹彩の二層構造など）も長文の中では埋没し、かえってアニメらしさを抑え込む。
- 対応として**短縮版プロンプト（生成用）**を追加した。二層運用: 生成のワークホースは短縮版、長文版は完全な仕様書・素材集として維持し、短縮版で足りない細部だけ長文版から移植する。短縮版では顔の作画指定を「人物画風参照画像のような、成熟した気品のある成人女性のアニメ顔」への委任に圧縮し、逆さ顔・波紋一つ・余分な指という高価値ガードだけを残した。
- 三度目の生成テストの知見: 下半分が「ファンタジー寄りの美麗イラスト」に留まり、人物画風参照から離れる場合、汎用の画風タグ（キービジュアル品質、セル塗り等）だけでは弱い。**「人物画風参照画像（2枚目）と完全に同じアニメ作画スタイルで描く」と参照画像そのものへ直接束縛し、踏襲すべき特徴を短いチェックリストで列挙する**のが効く。ただし瞳や髪の色は1枚目の人物参照に従う注記を添え、画風参照側のアイデンティティ（金髪、ターコイズの瞳）が混入するのを防ぐ。
- 生成後の微調整は上下を分けて指示する: 「上半分をもっと実写に、肌の質感をリアルに」「下半分のアニメ度を強く、セル塗りを強調して」。画風が参照から離れている場合は「下半分のアニメの顔と線画をもっと2枚目の画像に近づけて。目の形・まつ毛・陰影の切り分けを特に合わせて」。
- ほぼ狙い通りの生成結果が出たら、その画像を参照画像として添付し「上半分を完全に実写フォトリアリスティックに、下半分の反射を高品質アニメ調に」と指示すると、構図を保ったままスタイル分離だけを強化できる。
- 9:16 縦長は上下分割が綺麗に出やすいアスペクト比でもあり、本案の構図と合致している。

### 049・129との差（反射する内容から、反射する媒質へ）

- `049. 四季を映し分ける湖` は、同じ写真表現の中で湖面が四季を映し分ける。
- `129. 未来だけを映す湖` は、同じ写真表現の中で反射だけが一時間後を映す。
- 本案は、反射する時間や季節ではなく、**表現媒体そのものを実写からアニメへ変更する**。上の世界と下の世界で画材が変わる反射案。

### 181の知見（本人までアニメ化する失敗を逆方向に防ぐ）

- `181-mischievous-skin-doodles.md` では、実写人物までアニメ化する失敗を防ぐため `the real subject remains a photograph` を使用している。
- 本案ではこの知見を水辺線へ適用し、**水辺線より上は写真のまま、水辺線より下だけアニメ**という双方向のガードにした。
- アニメの倒影が一般的な別人へ変わらないよう、同じ顔の特徴、髪型、髪色、衣装、体型、ポーズを繰り返し明示した。

### 「現実半分・空想半分」群での位置

- `ideas/206-355-daily-thrill-fusion.md` の296〜310は、生活空間が異界へ直接続く構造。
- 本案では現実世界自体は変化せず、異界は湖の反射の中にだけ存在する。現実と空想の接続面を、水辺線一本へ圧縮した。

### 華やかなドレスの設計

- 華やかさを過度な露出ではなく、**スカートの量感、花弁状の多層構造、長いトレーン、星座図刺繍**で作る。
- ポーズと衣装は、ユーザーが提示した確定参考画像に合わせて改訂した: 前が短く後ろが長いハイローシルエット、持ち上げた前裾から白い多層チュールと踏み出した脚が膝下まで上品にのぞく、二の腕に落ちる短いドレープ袖、柔らかなドレープを寄せたボディス、素足、星と星を細い線で結ぶ星座図刺繍、踊るような一歩の途中で頭を軽く傾げるポーズ。これに伴い、当初の「完全な不透明総裏地」の指定は撤廃した。
- ネックラインだけを成人条件付きの可変要素にし、衣装全体のシルエットは年齢条件にかかわらず維持する。
- 画風参照画像の風を含んだ衣装の印象は、同じ衣装をコピーせず、花弁状の層と扇状のトレーンへ翻訳した。

### 反射の物理と接触の証明

- 上下反転、同じ縮尺、足元での接続、同じ顔の向き、同じ手とドレスの角度を明記し、第二の人物へ見える失敗を防ぐ。
- 波紋は一つだけに限定する。完全な鏡面を保ちながら、アニメ世界が貼り付けられた別画像ではなく、水に映っていることを示す。
- 指先は水へ触れさせず、伸ばしたつま先の一点だけを接触源にすることで、波紋の原因を一つに固定した（当初は前裾の接触だったが、確定したポーズに合わせてつま先へ変更）。

### 実写感とメディア分離

- 実写側は50mm、f/2.8、月光のみ、自然なセンサーノイズ、浅い被写界深度。
- アニメ側はクリーンな線、セル陰影、筆致のある背景、鮮やかな色。センサーノイズ、写真の肌、レンズボケを持ち込まない。
- 水辺線、照明、画質の三つのブロックでスタイル境界を繰り返し指定し、画風が上下へ漏れるのを防ぐ。

### 共通規約の適用

- 人物参照画像から年齢感、顔、髪、肌、体型、身体のライン、プロポーションを忠実に保持する。
- `never add or hardcode features that are not present in the reference` で勝手な特徴の追加を防ぐ。
- 手が目立つ構図のため、片手の役割を布の襞、もう片手の役割を開いた手に固定し、解剖学ネガを加えた。
- 表情は形容詞ではなく、「昔の夢へ戻ったように感じる」という内心から設計した。
- 独立した長い除外欄は設けず、既知の失敗だけを各ブロック内で具体的に防いだ。
