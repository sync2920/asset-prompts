# 52. 若手魔術師と、ハムスターの顔が潜むステンドグラス聖堂（参照画像ベース）

`51-crystal-oracle-hamster` の水晶玉・人物・神々しいハムスターの構図を維持し、
重いベルベットの古典ドレスを現代的な若手魔術師の服へ変更。背景は古い天文台から、
宝石色のステンドグラスに囲まれた魔法建築へ置き換える。ステンドグラスは一見すると
抽象幾何だが、離れた色面や鉛線を頭の中で結ぶと、耳・目・鼻・頬がハムスターの顔の
ようにも見えるパレイドリアとして設計する。

- **派生元:** `../51-crystal-oracle-hamster/variant-02-blue-hour-three-quarter.png`
- **アスペクト比:** 4:5 縦
- **成人条件:** 参照人物の成人としての見た目年齢を保持。「若い」は若返りではなく衣装と空気感のみ
- **衣装:** スクエアネックの完全不透明ドレス＋短い非対称ボレロ＋細い虹色パイピング。軽量なマットサテンとストレッチクレープ
- **建物:** 暗い石造リブ、尖頭アーチ、ステンドグラス天井と窓を持つ現実的な建築空間
- **ステンドグラス:** 多色の抽象幾何が先に見え、よく見ると顔らしさが浮かぶ。動物画・キャラクター絵にはしない
- **生成物:** `variant-01-abstract-rose-window.png` / `variant-02-distributed-triptych.png` / `variant-03-faceted-dome.png` / `variant-04-abstract-side-window.png`

## 生成時の4バリエーション

1. **抽象ローズウィンドウ:** 左後方に大きな放射状窓。顔らしい手掛かりを別々の同心円へ散らし、コバルト、紫、アンバー、ローズを中心にする。
2. **分散トリプティク:** 三連の尖頭窓へ手掛かりを分散し、建築全体を見たときだけ弱い顔のゲシュタルトが生まれる。ターコイズ、エメラルド、コバルト、マゼンタ中心。
3. **ファセットドーム:** ガラスドームのリブと上部窓へ耳・目らしい幾何を分散。紫、ルビー、淡金、オパールセントクリーム中心。
4. **抽象サイドウィンドウ:** 片側の大きな窓へ植物・天体の幾何として手掛かりを崩して配置。インディゴ、アンバー、シアン、ローズ中心。

## 設計メモ

- `29-water-stained-glass-sunflower` は床の水がステンドグラスへ変質する案。本案は建物そのものがステンドグラスで、模様のパレイドリアが物語を補強する。
- 初回生成では窓が一目で分かるハムスターの肖像になったため、耳・目・鼻・頬の候補を離れた領域へ分散し、頭部輪郭・ヒゲ・口・毛並みを作らない構造へ改訂した。
- 衣装の「若さ」は人物の年齢変更ではなく、軽量素材、短い丈の上着、直線的な切り替え、細い発光線で表現する。
- 人物の具体的な顔・髪・肌・体型は本文へ書き写さず、参照画像から保持させる。
