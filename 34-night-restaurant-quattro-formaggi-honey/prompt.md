# 34. 夜のレストラン、クワトロフォルマッジへ陶器の小さな器から蜂蜜（参照画像ベース）

`ideas/README.md` の人物参照方針に準拠し、人物の年齢、性別表現、顔、髪、肌、体型、胸と腰まわりの形と自然なボリューム、身長感、プロポーションなどを参照画像から精緻に保持する。おしゃれなイタリアンレストランで、焼きたてのクワトロフォルマッジへ小さな陶器製の器から蜂蜜を注ぐ瞬間を描く。人物、料理、店内を同じ夜の光で包み、現実の反射、屈折、湯気、ボケだけで幻想的な美しさをつくる。

- **アスペクト比:** 4:5 縦
- **見せ場:** 陶器の丸い縁からピザまで切れずにつながる、太く滑らかな蜂蜜の一筋
- **人物:** カメラへポーズを取らず、蜂蜜が落ちる先を見つめる自然な食事中の一瞬
- **料理:** 白いクワトロフォルマッジ。4種のチーズ、焼けた気泡、豹柄状の焦げ、蜂蜜の艶を個別に読めるようにする
- **器:** 手のひらほどの白い陶器製。小さな持ち手、円筒形の胴、丸い開口部と厚みのある縁を持ち、長い注ぎ口は付けない
- **光:** 深い紺色の夜景、キャンドル、真鍮の照明、蜂蜜、チーズ、陶器の釉薬を同じ金色の反射で結ぶ
- **既存案との差:** `07` はフォークとカメラ目線を中心にした夜のディナー。本案は料理を見つめる横方向の所作、陶器から落ちる蜂蜜、ピザと夜の光の一体化を中心にする
