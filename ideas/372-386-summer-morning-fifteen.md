# 372〜386 — 夏の朝投稿用15案

8月の朝らしい「暑さが始まる前の光・水気・風」を軸にした15案。既存の朝投稿案で使用済みの
キッチンの湯気、朝ラン後の自販機、ホテルのカーテン開け、庭の水やり、河川敷の歩行、
ベランダの洗濯、電車窓のうたた寝、公園の猫、湖の水切り、神社の手水、高原牧場などを外し、
朝の行動と場所を新しく組み合わせた。

参照人物は明確に成人で、柔らかく明るい雰囲気と、風・水・木漏れ日に動きが出る髪型が特徴。
そのため健やかさを中心に、静謐、かっこよさ、生活の余韻、上品な親密さを散らしている。
ポーズはいずれも動作の途中を前提とし、衣装の見せ場は一案につき一箇所に絞る。プロンプトは
依頼どおり未作成で、採用時に `ideas/README.md` の共通テンプレートから組み立てる。

- **比率:** 4:3×2、3:4×3、4:5×2、9:16×3、16:9×4、1:1×1
- **トーン:** 健やか／静謐／かっこいい／生活の余韻／上品／だらしない生活感／幻想寄り
- **主な朝の媒体:** 朝靄、露、水面、湯けむり、砂、風、すだれの影

## 372. 早朝の並木道、犬の散歩を待つ

- **比率:** 4:3 横 / **トーン:** 健やか
- **見せ場:** ケヤキ並木の朝靄。犬が草むらの匂いを確かめる間、リードを両手に持って立ち止まる一瞬。露に濡れたスニーカーと、斜光に浮かぶ草の水滴。
- **既存との差:** 動物ものは27（ベンチの猫・手の匂い）が中心。こちらは犬との散歩中の「待ち」と、奥行きのある並木道を主題にする。
- **差し替え変数:** 犬種、並木の種類、リードの色、靄の濃さ。

## 373. 朝の海、サーフボードを抱えて波を読む

- **比率:** 9:16 縦 / **トーン:** かっこいい
- **見せ場:** 朝練前、ウェットスーツを腰で結び、ボードを脇に抱えて沖を見る横顔。まだ人のいない浜と、風が入る前の滑らかな朝の波。
- **既存との差:** 既存の海案は水着、建築、幻想が中心。朝のスポーツとして波を観察するサーフィンは未使用。
- **差し替え変数:** ボードの色、ウェットスーツの色、波の大きさ、時刻（日の出直後 ↔ 六時台）。

## 374. 朝市の白木テーブル、トマトを朝日に透かす

- **比率:** 3:4 縦 / **トーン:** 生活の余韻
- **見せ場:** 青空朝市。木箱に並ぶ夏野菜からトマトを一つ選び、低い朝日にかざして赤い透過光を確かめる手元。周囲には露の残るきゅうりと、皮付きのとうもろこし。
- **既存との差:** 312（早朝の魚市場）は氷と発泡スチロールに囲まれた働く側の場面。こちらは屋外の野菜市場で買う側を描き、野菜を通る朝の光を焦点にする。
- **差し替え変数:** 品物（トマト ↔ 桃 ↔ プラム）、テーブルの素材、市の規模。

## 375. 六時に自然に目が覚めた寝室、光の矩形

- **比率:** 4:5 縦 / **トーン:** だらしない生活感・親密さ
- **見せ場:** 白いリネンシーツを肩まで引き上げたまま、窓の斜光がベッドに落とす矩形の中で、伸びをする直前の寝起き顔。寝癖とシーツのしわが朝までの時間を残す。
- **既存との差:** 09は夜のベッドと素材表現、082は寝過ごした正午。こちらは朝六時台に自然に目覚めた瞬間を、透けを使わずシーツの遮蔽と光で描く。
- **設計上の例外:** シーツと緩い寝間着で身体の輪郭を意図的に隠し、見せ場を寝起きの表情と布のしわに限定する。
- **差し替え変数:** 窓の向き、シーツの色（白 ↔ 生成り）、光の矩形の角度。

## 376. 朝靄の湖でSUP、立ち上がる途中

- **比率:** 16:9 横 / **トーン:** 静けさ・健やか
- **見せ場:** 鏡のような湖面で、ボード上の膝立ちから立ち上がる途中。パドルを支える手元と、ボードから広がる細い波紋が、静かな水面に唯一の動きをつくる。
- **既存との差:** 368は岸から石を投げる朝の湖、13・21は夜の湖。こちらは水上へ出て、自分の重心で水面を動かす朝にする。
- **差し替え変数:** ボードの色、ウェア（ラッシュガード ↔ 薄手ウィンドブレーカー）、靄の深さ。

## 377. 朝霧の茶畑、芽を摘む指先

- **比率:** 3:4 縦 / **トーン:** 静謐
- **見せ場:** 畝のラインが朝霧の奥へ消える茶畑。しゃがんで一芯二葉を摘む指先と、籠に重なる柔らかい緑。葉の露が指へ移る瞬間。
- **既存との差:** 371は高原牧場の風と氷菓が主題。茶畑の畝、朝霧、摘採の細かな手仕事を組み合わせた案は未使用。
- **差し替え変数:** 畑の傾斜、服装（前掛け ↔ 作業シャツ）、霧の濃さ。

## 378. 潮干狩りの干潟、初めてのあさり

- **比率:** 4:3 横 / **トーン:** 健やか
- **見せ場:** 朝の干潟。熊手を持ってしゃがみ、見つけた最初の貝を泥のついた指先で確かめる一瞬。広い干潟には、低い朝日の反射帯が細く伸びる。
- **既存との差:** 海辺の案は多数あるが、干潮時だけ現れる地形と、貝を探す手の動作を主題にした潮干狩りは未使用。
- **差し替え変数:** 貝の種類、干潟の広さ、服装（Tシャツ ↔ ラッシュガード）。

## 379. 波打ち際、裾を持ち上げて波を待つ

- **比率:** 9:16 縦 / **トーン:** 上品
- **見せ場:** 朝日を浴びた波打ち際。ミモレ丈スカートの裾を両手でそっと持ち上げ、次の引き波が足首を洗うのを待つ静止。白い泡と濡れた砂の反射を主役にする。
- **既存との差:** 18・356は川沿いの歩行とシフォンを通る光。こちらは海辺で立ち止まり、完全不透明な布、持ち上げた裾、波の泡だけに焦点を絞る。
- **差し替え変数:** スカートの色と丈、波の高さ、朝日の角度。

## 380. 稜線でご来光を待つ

- **比率:** 9:16 縦 / **トーン:** 静謐・かっこいい
- **見せ場:** 夜明け前に登り切った山頂。標識に片手を添え、稜線の向こうから顔を出す朝日を待つ。ウィンドブレーカーの裾だけが山の風に小さく鳴る。
- **既存との差:** 山間の既存案は植物園や渓流が中心で、山頂・稜線は未使用。既出の雲海表現は使わず、稜線の輪郭と朝日の位置で構成する。
- **差し替え変数:** 山の季節感（夏山 ↔ 残雪）、ウェアの色、朝日の位置。

## 381. あぜ道の朝、稲の露と逆さの朝日

- **比率:** 16:9 横 / **トーン:** 健やか・静謐
- **見せ場:** 8月の緑の田んぼ。あぜ道を歩く足元で、水面に映る逆さの朝日の中を進む。稲の葉先の露が光り、手を伸ばして葉へ触れる途中。
- **既存との差:** 015は屋上の水たまりを使う人工的な鏡、368は湖面の遊び。こちらは田の水面、稲、あぜ道の歩行で夏の生活景をつくる。
- **差し替え変数:** 田の枚数、あぜ道の素材（土 ↔ 舗装）、朝日の高さ。

## 382. 温泉街の朝、湯けむりの石畳

- **比率:** 3:4 縦 / **トーン:** 静謐・上品
- **見せ場:** 人通りのない朝の温泉街。生成りの宿浴衣に薄い羽織を重ね、下駄で石畳を下る途中に湯けむりの筋を横切る。焦点は裾の動き、足元、湯けむりの層。
- **既存との差:** 既存の浴衣案は夜の花火帰りで、墨青の色とうなじが焦点。こちらは朝、生成り、足元、湯けむりへ主題を切り替える。
- **差し替え変数:** 温泉街の地形（石段 ↔ 川沿い）、浴衣の色、湯けむりの量。

## 383. 自転車で坂を下る朝の風

- **比率:** 4:5 縦 / **トーン:** 健やか・かっこいい
- **見せ場:** 住宅街の長い下り坂。ペダルを止めて風に乗る一瞬を斜め前から捉え、髪の流れを主役にする。服装は自転車に適したトップス、ワイドパンツ、スニーカー。
- **既存との差:** 247は二人乗りの後ろから相手の背中を見る構図。こちらは一人乗り、斜め前、下り坂の風に焦点を置く。
- **差し替え変数:** 自転車の種類（シティサイクル ↔ クロスバイク）、坂の街並み、風の強さ。

## 384. 砂浜に描いた朝の絵、波が消す前

- **比率:** 16:9 横 / **トーン:** 幻想寄りの静けさ
- **見せ場:** 人のいない朝の浜。砂に大きく描いた一輪の花のそばにしゃがみ、最初の波が絵の端へ届く直前を見ている。引きの構図で砂の絵全体と小さな人物を見せる。
- **既存との差:** 297・303・既存の浅瀬案は現実へ異界が混ざる構成。こちらは異変を使わず、「描いたものが波で消えるまで」という現実の短い時間だけを物語にする。
- **差し替え変数:** 絵のモチーフ（花 ↔ 魚 ↔ 渦）、描く道具（枝 ↔ 指先）、波までの距離。

## 385. すだれ越しの縞の光、目を細める

- **比率:** 1:1 正方形 / **トーン:** 生活の余韻
- **見せ場:** すだれ越しに入る朝日が、顔と肩に細かな縞の光を落とすクローズアップ。外を見るために目を細める表情と、光と影の模様だけで朝を示す。
- **既存との差:** すだれを光学的な格子として使う案は未使用。環境を広く写さず、1:1の顔寄り構図で光の模様だけを主題にする。
- **差し替え変数:** すだれの編み目、顔の角度、背景の庭のボケ。

## 386. 早朝のロープウェイ、朝霧の街を越える

- **比率:** 16:9 横 / **トーン:** かっこいい・旅
- **見せ場:** 始発のゴンドラを一人で貸し切ったような静かな車内。窓いっぱいに朝霧の層と、その下に沈む街。手すりに片手を添えて見下ろす横顔へ、昇ってきた朝日が当たる。
- **既存との差:** 空港や駅を舞台にした朝の旅は既出だが、空中を移動しながら都市と霧の高度差を見せるロープウェイは未使用。
- **差し替え変数:** ゴンドラの色、眼下の景色（街 ↔ 湖 ↔ 渓谷）、霧の高さ。
