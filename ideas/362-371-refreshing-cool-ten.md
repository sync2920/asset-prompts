# 362〜371 — 清涼系10案（涼の源をばらすシリーズ）

`12-afternoon-rooftop-juice`（= 205）のトーン、すなわち「真夏の日常の中の一瞬の涼 × プロのエディトリアル実写 × candid な動作の途中」を継承しつつ、既視感を避けるために 12 の構成要素（屋上・缶ジュース・頂光と短い影・風で膨らむ布）は一切使わず、「涼の源」だけを10種に分解して各案の主題にしたシリーズ。既存ストック（001〜361・直下01〜27）で清涼系として使用済みのモチーフ（縁側スイカ・風鈴・かき氷・氷を口に含む・炭酸の栓・製氷所・冷凍庫・プール・噴水・水たまり・シャボン玉・ビー玉・アイス・祭り面など）をすべて除外し、未使用の源だけで組んでいる。トーン（健やか／生活の余韻／幻想／静謐／光の実験）、時間帯（早朝〜夕方）、比率（4:5×3、3:4×3、9:16、16:9×2）は散らしてある。参照人物（明確に成人、明るく柔らかい雰囲気、外はねボブ）は水・風・木漏れ日と相性がよく、全案で無理なく成立する。

- 涼の源の内訳: 362 生の水 / 363 泡と冷房 / 364 水中光 / 365 流れる川 / 366 木陰と揺れ / 367 祭りの水盤 / 368 鏡面の湖 / 369 日傘の影 / 370 清めの水 / 371 丘の風と氷菓

## 362. 公園の水飲み場、立ち上る水に顔を寄せる

- **比率:** 4:5 縦 / **時間:** 昼 / **トーン:** 健やか
- **見せ場:** 木陰の水飲み場。蛇口をひねって勢いよく立ち上がる水の弧に、飲む前に両手を添えて顔を近づける一瞬。跳ねた水滴が木漏れ日で光り、濡れた前髪が額に貼りつく。
- **12との差:** 12 は「冷たい缶を唇に当てる」小道具経由の涼。こちらは水そのものに素手と顔で触れる、容器なしの涼。
- **既存との差:** 水に触れる場面は 231（冬の米研ぎ）のみで、夏の水飲み場は未使用。
- **差し替え変数:** 場所（公園 ↔ 神社の境内 ↔ 運動場の隅）、時間帯（朝 ↔ 昼）、木陰の種類。

## 363. 純喫茶のクリームソーダ、泡が弾ける音を聞く

- **比率:** 4:5 縦 / **時間:** 午後 / **トーン:** 生活の余韻・レトロ
- **見せ場:** 冷房の効いた薄暗い店内、すりガラス越しの柔らかい光。深緑のソーダに白いバニラが浮かび、炭酸の泡がグラスの縁で細かく弾ける。ストローを刺す前、耳を少し傾けて泡の音を聞く一瞬。
- **12との差:** 外の猛暑の中の涼 → 冷房と日陰の「室内の涼」。飲み物は脇役、泡と緑色が主題。
- **既存との差:** 16（パリのカフェテラス）は外・コーヒー。334（炭酸の栓の霧）は開栓の一瞬のクローズ。昭和喫茶の店内は未使用。
- **差し替え変数:** ソーダの色（メロン緑 ↔ ブルー ↔ いちご）、席（カウンター ↔ 窓際ボックス）、店の年代感。

## 364. 水族館、クラゲ水槽の青い光

- **比率:** 3:4 縦 / **時間:** 昼 / **トーン:** 非日常・幻想寄りの清涼
- **見せ場:** ひんやりした展示室、壁一面のクラゲ水槽。青い光が揺れて顔と白い服の上をゆっくり流れる。水槽を見上げる横顔に、クラゲの傘の影が波紋となって落ちる。
- **12との差:** 白い頂光の下の汗ばむ空気 → 青い水中光の冷たい空気。光が「上からの太陽」ではなく「横からの水」を通る。
- **既存との差:** 040（閉館後の水族館）は夜の非日常、50-41 はタイトルのみ。営業中の昼・クラゲ特化は未使用。
- **差し替え変数:** 水槽の種類（クラゲ ↔ 大水槽の魚群 ↔ トンネル水槽）、光の色（青 ↔ シアン）、距離（見上げる ↔ 額を近づける）。

## 365. 渓流に足を浸す、流れに負ける足先 → **28 として採用**（実生成版は小さなおにぎり追加・トップスをバブルヘムに変更した昼食変種）

- **比率:** 9:16 縦 / **時間:** 午後 / **トーン:** 健やか・自然
- **見せ場:** 山間の清流、大きな岩に腰を下ろしてスカートの裾をまくり、足先を流れに浸す。水しぶきがすねに当たり、木漏れ日が水面の反射で脚に揺れる。冷たさに肩をすくめる直前の顔。
- **12との差:** コンクリートの暑さ → 山の冷気。体に触れる冷たさが「唇」から「足先」へ。
- **既存との差:** 18/356（河川敷歩行）は歩く動作、こちらは静止して水に浸かる。
- **差し替え変数:** スカート色、時間帯（午前 ↔ 午後）、渓流の規模（せせらぎ ↔ 本流筋）。

## 366. 木陰のハンモック、昼寝から覚めた一秒

- **比率:** 16:9 横 / **時間:** 昼下がり / **トーン:** だらしない・気持ちいい
- **見せ場:** 大きな木の下のハンモック。胸の上で開いたままの文庫本、揺れる木漏れ日が瞼の上を通る。目が覚めて「何時だろう」と空を見上げた一瞬。風が来るたびハンモックが浅く揺れる。
- **12との差:** 立って飲む能動の涼 → 横になって揺れる受動の涼。
- **既存との差:** 337（柱時計と昼寝）は畳の室内。屋外ハンモックは未使用。
- **差し替え変数:** ハンモックの色（生成り ↔ 縞 ↔ 色布）、木の種類、本の有無、風の強さ。

## 367. 縁日の金魚すくい、水盤の青に顔を近づける

- **比率:** 4:5 縦 / **時間:** 夕方 / **トーン:** 祭り・賑わいの中の一点の涼
- **見せ場:** 夕涼みの縁日、金魚すくいの屋台。青い水盤を覗き込むと、水面の反射光が下から顔に揺れて乗る。ポイを水に沈める直前の真剣な目。周りの提灯の賑わいはボケて、水の青だけが鮮明。
- **12との差:** 一人の静寂の涼 → 祭りの喧騒の真ん中にある一点の涼。
- **既存との差:** 278（金魚鉢に星空）は室内のマジックリアリズム。103・248 は祭りの別側面（面・人混み）。
- **差し替え変数:** 屋台（金魚すくい ↔ ヨーヨー釣り）、提灯の色、夕方の深さ（薄暮 ↔ 日没後）。

## 368. 早朝の湖、石の水切りが跳ねる

- **比率:** 16:9 横 / **時間:** 朝 / **トーン:** 静けさ・遊び
- **見せ場:** 朝靄が残る鏡のような湖面。腰を落として平らな石を投げ、水面を四回、五回と跳ねるのを目で追う。飛沫と広がる輪だけが静けさを破る。
- **12との差:** 「飲む前の静止」 → 「投げたあとの運動」。清涼は飲み物ではなく朝の空気と水。
- **既存との差:** 13/21（湖）は夜と流星群、049/129 の湖は幻想。朝の遊びとしての湖は未使用。
- **差し替え変数:** 湖 ↔ 静かな川、跳ねる石の数、朝靄の濃さ。

## 369. 白い日傘の内側、持ち歩く木陰

- **比率:** 4:5 縦 / **時間:** 真昼 / **トーン:** 光の実験・上品
- **見せ場:** 照りつける白い歩道。白い日傘を浅く差し、傘の内側だけに涼しい柔らかい影が落ちる。顔は影の中、肩から先は白い光。傘の縁を少し上げて眩しい世界を覗く一瞬。
- **12との差:** 12 と同じ「ほぼ頂光」の条件に対し、12 は「受けて短い影を足元に落とす」、こちらは「逃れて影を持ち歩く」逆の答え。頂光を使う唯一の変奏で、差であることを設計メモに明記する。
- **既存との差:** 277（影だけが傘を差す）はマジックリアリズム、50（傘）は雨。日傘は未使用。
- **差し替え変数:** 傘の色（白 ↔ 生成り ↔ 内側だけ淡色）、場所（白い歩道 ↔ 駅前広場 ↔ 橋の上）、時間（真昼 ↔ 午後）。

## 370. 早朝の神社、手水舎の水で手を清める

- **比率:** 3:4 縦 / **時間:** 早朝 / **トーン:** 静謐
- **見せ場:** 誰もいない境内、苔むした手水舎。柄杓から流れる細い水が両手のひらに落ち、滴が石に弾ける。蝉が鳴き始める前の、まだ夜の冷気が残る空気。清めの仕草の途中の伏し目。
- **12との差:** 暑さのピークの午後一 → 暑さが始まる前の早朝。「飲む水」ではなく「清める水」。
- **既存との差:** 50-27（神社の石段）はタイトルのみ、039 は冬の初詣。夏の早朝の手水は未使用。
- **差し替え変数:** 社 ↔ 寺、手水鉢の石の色、苔の有無、早朝の時刻（夜明け直後 ↔ 六時台）。

## 371. 高原牧場のソフトクリーム、溶けるまでの三十秒

- **比率:** 3:4 縦 / **時間:** 午前 / **トーン:** 健やか・開放感
- **見せ場:** 緑の丘と低い空、水平に吹く風。買ったばかりのソフトクリームの先端が風でわずかに崩れ始め、舐める前に「あ、やばい」と笑う一瞬。白いソフトと青い空と緑の丘の三色だけの画面。
- **12との差:** 「缶の冷たさを唇で確かめる」 → 「溶ける時間と戦う」。風は布を膨らませるのではなく水平に髪を流す。
- **既存との差:** アイス系は 102（梅雨明けバス停）・246（差し出す手）のみ。牧場・高原は全ストックで未使用。
- **差し替え変数:** ソフトクリームの味（バニラ ↔ ミルク ↔ ミックス）、丘の作物（牧草 ↔ そば畑）、風の強さ。
