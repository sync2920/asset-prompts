# 200 — 朝の庭で植物に水、霧の光柱（だらしない色気・生活の余韻）

197〜199 に続く朝投稿用の1案。199が「薄い布を通る逆光で体を影絵にする」だったのに対し、本案は**「霧（空気）を通る朝の斜光で体を輪郭にする」**という逆の表現アプローチ。透過の媒質を布ではなく環境（霧・飛沫）に移すことで、布を透かさずに柔らかな輪郭を描く。視覚のフックは**ホースの霧が低い朝日を浴びて光の粒子の柱になる一瞬**。

- `never add or hardcode features that are not present in the reference image` を入れる（共通規約）。

- **比率:** 3:4 縦長
- **見せ場:** 霧の光柱の中に浮かぶ彼女の輪郭と、朝日を仰ぐ横顔。路面に長く伸びる影。
- **差し替え変数:** 水やりの場所（裏庭デッキ、石畳の坪庭、ベランダの植木鉢）、シャツの色、季節の植物。

## 設計メモ

### 199との差（透過の媒質を変える）

- 199: **布**（薄いバスローブ）を通る逆光 → 布の中に体が影絵として浮かぶ。
- 200: **空気（霧）＋ほのかに透ける薄い布**の二重の透過 → 霧の中に輪郭が浮かび、布の単層部は光を通して体の影形を暗示する。肌色・下着ディテールは透かさず、布が重なる部分は不透明のまま。

透過媒質を「布のみ」「空気のみ」から「布＋空気の二重」に拡げた。`expression/01` の「光学言い回し」を布と光と飛沫の両方に適用した変奏。

### 197との差（同じ「着古しシャツで隠す」例外でも）

- 197: キッチン、マグの湯気が光の柱。室内、接写寄り、4:3 横。
- 200: 裏庭、ホースの霧が光の柱。屋外、全身、3:4 縦。視覚のスケールと「影が伸びる」構図を変えた。

### 共通規約の適用

- 「着古して薄くなったシャツ＋ほのかす透け」を明記し、胸のシルエット指定は入れず、体は光のふるまい（影形）としてのみ読ませる（README「意図的に緩い服で隠す案は例外として明記する」「透け感には必ず構造をつくる」を折衷）。
- **手元・ホースの明示**: ホースの経路（蛇口→画面外→足元で輪→手）とノズルの持ち方（片手でピストルグリップ一本）を明記し、両手の役割を固定。README「手が目立つ構図には解剖学ネガ」に従い `no extra fingers, no malformed hands, no second hose end` を追加。
- `never add or hardcode features not present in the reference` でモデルの勝手な特徴持ち込みを防ぐ。
- 表情は形容詞でなく内心（still half-asleep, breathing the cool air）。
- カメラブロックで証明写真風を回避、霧を暗背景に対置して粒子をくっきり読ませる。
