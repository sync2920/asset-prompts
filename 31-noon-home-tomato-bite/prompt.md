# 31. 自宅の昼、正面を向いたままトマトを一口（参照画像ベース）

`ideas/README.md` の人物参照方針に準拠し、人物の顔・髪・肌・体型・胸と腰まわりの形と自然なボリューム・身長感・プロポーションなどの身体的特徴を参照画像から精緻に保持する。夏の正午ごろ、自宅の小さなダイニングでトマトサラダとカプレーゼを食べている日常の一枚。身体と顔をカメラへまっすぐ向け、頭をかしげず、カメラ目線を保ったままフォークのミニトマトを自分の口へ運ぶ瞬間を捉える。

- **アスペクト比:** 4:5 縦
- **見せ場:** 正面を向いたまま、赤いミニトマトが唇へ触れる直前の一瞬。両目・フォーク・トマトを同時に明瞭に見せる
- **姿勢:** 肩と顔をカメラへ正対。頭は垂直かつ水平で、横への傾き・三分の一横顔・横顔を使わない
- **仕草:** カメラ目線を保ち、身体の外側からフォークを自分の口の中央へ運ぶ。視聴者へ差し出す動作にはしない
- **料理:** 彩りトマトのサラダ、トマトとモッツァレラとバジルのカプレーゼ、結露した冷水
- **服装:** 淡いバターイエローの半袖ファインリブニット。完全不透明で、夏の自宅昼食に合う簡素な装い
- **背景:** 生活感を抑えて整えた自宅のダイニングキッチン。カフェ、レストラン、テラスにはしない
- **既存案との差:** `07` は夜のレストランデート、`24` はレトロなカフェテリア。本案は自宅の昼食と正面カメラ目線を軸にする

## 設計メモ

### 正面向きの固定
- 身体は肩・胸骨からカメラへ正対させ、顔は額・鼻・唇・顎をレンズ中央の垂直軸へ揃える。
- `both eyes sit on the same horizontal line` と `no three-quarter facial angle, no profile` を併記し、首をかしげた可愛いポーズや横顔への収束を抑える。
- カメラも人物の真正面・着座時の目線高へ固定し、ダッチアングルや左右非対称の遠近を使わない。

### 自分で食べる動作の固定
- フォークは身体の外側から入り、口の中央へ向かう軌道とする。視聴者へ向けて差し出す軌道にはしない。
- ミニトマトが唇へ軽く触れ、口が一口分だけ自然に開いた時点を切り取る。
- フォーク上の具材をミニトマト一個に限定し、料理とフォークの関係を明瞭にする。

### 自宅の昼食
- 背景を木のテーブル、淡い壁、コンパクトなキッチンカウンター、最低限の生活用品へ絞る。
- 正午らしさは、窓からの白い夏光、テーブル上の短い影、冷水グラスの結露で表す。
- カフェやレストランへ変化しないよう、メニューボード、業務用設備、テラス家具を明示的に置かない。
