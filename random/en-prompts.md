# 英語プロンプト集（単体で投げられる完成形）

`safe.md` の12シーンを、それぞれ**そのままコピペで投げられる形**に展開したもの。
人物（顔・体型・髪）はシーンごとに別々の組み合わせを割り当て済みなので、
12本を順に投げるだけで12人ぶんのバリエーションになる。

- 顔・体型・髪だけ差し替えたい → 末尾の「差し替え用スロット」から該当部分を入れ替える
- ネガティブ欄があるツールでは、共通ネガティブ（末尾）を貼る。無いツールでは貼らない
- 安全フィルタ対策として全プロンプトの冒頭に成人・着衣の宣言を入れてある（詳細は [safe.md](safe.md)）

## 共通ネガティブプロンプト

ネガティブ欄があるツール（SD / ComfyUI / NovelAI 等）でのみ使う。
内容語は一切入れず、技術的破綻だけを列挙している。

```
anime, illustration, painting, stylized, CGI, 3D render, plastic skin, doll-like face, mannequin, distorted anatomy, exaggerated proportions, deformed hands, extra fingers, fused fingers, extra limbs, harsh flash, blown highlights, heavy makeup, watermark, text, logo, low resolution, blurry
```

Midjourney の場合は末尾に:

```
--ar 3:4 --style raw --no anime, illustration, 3d render, plastic skin, deformed hands, extra fingers, text, watermark
```
